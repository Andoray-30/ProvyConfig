# 新子域名与家庭入口

假设你新建 `home-gw.你的域名` 和 `home-sub.你的域名`：在 config.yaml 的 domains.gateway / domains.subscription 填真实名称，示例名称不可直接使用。可以使用 sync-api.xyz 下的新子域名，但不要改动现役 gw.sync-api.xyz / sub.sync-api.xyz 的解析。

## 如何连接

| 用途 | 新部署处理方式 |
|---|---|
| 新订阅子域名 | HTTPS `/s/令牌` → 本包 Caddy → 127.0.0.1 的订阅服务 |
| 动态规则 | 同一私有路径 `/s/令牌/rules/版本/文件.mrs`，每日更新后的完整包 |
| 新节点子域名，TCP | VLESS/WS/TLS → Caddy → `/dispatch/国别类型` 对应的本机入口 → 已选上游 |
| 新节点子域名，UDP | HY2 直接进入本包 Mihomo，按认证绑定同国苏菲一倍 HY2 池 |
| 原始上游 | 家庭服务器直接连接原始订阅中的地址；不经过阿里云或 sync-api.xyz 的旧入口 |

发布节点地址、SNI／Host、入口直连规则、DNS 例外和规则下载地址均由配置生成。默认 TCP 和 UDP 都是 443，不冲突；Caddy 明确禁用 HTTP/3，避免抢占 HY2 的 UDP 443。控制器、核验入口和逐节点探测端口保持回环监听，不对外暴露。

## DNS 与端口

1. 两个新子域名的 A 记录都指向家庭公网 IPv4；动态 IP 需要你已有的 DDNS 同步。不要误填家庭 LAN 的 192.168／10.* 地址。
2. 两条记录均使用 **仅 DNS / DNS-only**。普通 Cloudflare 橙云不能转发这个 HY2 UDP 入口；为了对照真实家庭路径，本包两个入口都不要套 HTTP CDN。
3. 默认路由器转发 TCP 80、TCP 443、UDP 443 到家庭服务器固定 LAN 地址。TCP 80 用于 ACME HTTP 验证；不要把 SSH、28190/28192/29190、284xx/286xx、31000–31999 暴露出去。
4. 本包当前入口按 IPv4 监听，保留现有客户端国内 IPv6 策略；新域名不要添加不可达的 AAAA。家庭原生 IPv6 入站需要另行验证／适配，不能仅添加 AAAA 就认为可用。
5. 先核对是否有公网 IPv4。处于 CGNAT、运营商封入站、路由器不支持映射时，两个域名可解析不代表入口可达；先用 local-test 比较上游，不要自动新增外部隧道导致对照路径变化。
6. 从手机移动网络测试入口，以排除路由器不支持 NAT 回环的问题。同一 LAN 内访问公网域名失败而移动网络成功，检查回环或本地分域 DNS，不关闭证书校验。

可以配置不同端口，但公网 HTTPS、HY2 端口必须分别等于 config.yaml 中 https_port／hy2_port；不要只改变路由器外端口，客户端却仍拿到旧端口。DNS 不携带端口。非 443 HTTPS 端口也会写入订阅及规则 URL。自动 ACME 仍需要标准公网挑战入口（通常 TCP 80）。

## 证书

默认 tls.mode=auto：独立 Caddy 通过 Let's Encrypt 为两个新域名获取／续期证书。配置明确指定容器存储根 `/data`，映射到宿主 data/caddy，证书位于其 certificates/ 下，不依赖镜像的 XDG 默认目录层级。HY2 读取其中 gateway 域名的证书文件，不复制私钥、不设第二套续期任务。启动适配器核对证书有效期、域名和公私钥匹配；客户端还会校验信任链。

如果已有证书管理器：tls.mode=manual，证书与私钥放 `certs/`，配置容器内绝对路径 `/certs/fullchain.pem`、`/certs/privkey.pem`。此模式使用一份同时覆盖两个新子域名的证书。私钥 chmod 600。续期由你的原管理器负责，证书更新后重新创建本包 Caddy 容器，确认 HY2 新连接验证通过；本包不替你复制私钥或改变证书管理器。

新部署必须使用自己的证书和凭据。不能复制阿里云 data／secrets／证书，也不能在客户端启用 skip-cert-verify 掩盖问题。

## 常见现象

- 订阅 HTTPS 连接不上：检查新 DNS、TCP 映射、Caddy 证书；不要通过已经失效的节点更新订阅。
- 订阅返回 503：HTTPS 已到达，但暂没有合格可发布节点；查看 dispatch 状态和完整扫描结果。
- VLESS 可用、HY2 全部超时：检查 UDP 映射／防火墙、DNS-only、Caddy HTTP/3 是否关闭，再看国别 HY2 是否 ready。
- 某国 HY2 不显示：不是域名漏配；只发布已合格的苏菲一倍 HY2。恢复合格后更新订阅，不能借用机房或其他国家。
- 证书等待超时：检查两个域名、ACME 邮箱、TCP 80、公网 IP。准备脚本不会修改 DNS／路由器／防火墙。
